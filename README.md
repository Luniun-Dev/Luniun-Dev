## 🇫🇷 En français

Bienvenue chez **Luniun Dev**, un projet de développement indépendant basé en France.

Nous concevons des applications Android et des outils pratiques, avec un goût particulier pour les jeux vidéo, les assistants numériques et l'expérimentation technique.

### 🎮 Projet à l'honneur : Medieval Dynasty Companion

**Medieval Dynasty Companion (MDC)** est une application Android en développement pour accompagner les joueurs de *Medieval Dynasty*.

L'objectif : rendre les informations du jeu plus faciles à consulter et proposer des outils utiles pendant une partie.

> 🌐 [Découvrir Luniun Dev sur notre site officiel](https://luniun-dev.fr)  
> 🚧 Application en développement : le lien de téléchargement sera ajouté dès sa disponibilité.

### 🤝 Contributions open source

Nous souhaitons aussi aider d'autres développeurs : analyser des problèmes, tester, améliorer la documentation et proposer des corrections concrètes.

Nous privilégions les contributions utiles, transparentes et respectueuses des mainteneurs.
